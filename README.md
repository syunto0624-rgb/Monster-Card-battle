# モンスターカードバトル — ARCANA DUEL

ブラウザーで遊べる、1対1の2Dカードバトルゲームです。CPU対戦と、同じ画面を使った2人交代対戦に対応しています。

## すぐに遊ぶ

1. このリポジトリを **Code → Download ZIP** からダウンロードし、展開します。
2. `arcana-duel.html` を Chrome、Edge、Safari などのブラウザーで開きます。
3. 手札のカードをクリックし、右側の詳細欄から召喚・魔法・装備を使用してください。

ゲームの起動にインストールやビルドは不要です。Google Fonts を読み込むため通信する場合がありますが、通信できなくても代替フォントでゲームを実行します。

## 実装済み機能

- CPUとの対戦
- 同じ端末での2人交代対戦（交代時の準備画面あり）
- 180種類のカードを閲覧できる図鑑と、名前・能力・種類・種族・レアリティによる絞り込み
- 40枚のデッキ編集。同じカードは3枚まで
- ブラウザーのローカルストレージへのデッキ保存
- モンスターの召喚、魔法、アイテムの装備
- 直接攻撃、モンスター同士の戦闘、ブロッカーによる防御
- 体力・エネルギー・残りデッキ枚数・墓地枚数・対戦ログの表示

## ビジュアルテーマ

魔法とテクノロジーが共存する「ファンタジー × サイバー」。ネイビーの戦場にシアン・紫の光と古金色の装飾を重ね、魔法陣と回路、紋章とホログラムを組み合わせています。カードイラストにも召喚リングと回路フレームを追加しています。

## カード構成

| 種類 | 種類数 | 役割 |
| --- | ---: | --- |
| モンスター | 100 | フィールドに召喚して攻撃・防御 |
| 魔法 | 50 | ダメージ、回復、ドロー、エネルギー増加、強化など |
| アイテム | 30 | 味方に装備してパワーや能力を追加 |
| 合計 | 180 | 図鑑で全カードを確認可能 |

モンスターの種族は、ドラゴン・獣人・精霊・機械・アンデッド・天使・悪魔・海獣・妖精・魔導士の10種類です。

レアリティは **ノーマル（N）→ レア（R）→ スーパーレア（SR）→ ハイパーレア（HR）→ ウルトラレア（UR）** の5段階です。高レアリティはパワーや効果量が大きくなる設計ですが、カードの役割やコストによって強さは変わります。

## 基本ルール

### 初期状態とターン

- デッキ40枚、手札6枚、エネルギー0、体力4000から開始します。
- 各プレイヤーのターン開始時、エネルギー総量が1増え、現在のエネルギーが総量まで回復します。
- ターン開始時にカードを1枚引きます。先攻の最初のターンも引くため、最初に表示される手札は7枚、エネルギーは1です。
- カードを使用すると、表示されているコスト分のエネルギーを支払います。
- 一部のカードは、ターン中にエネルギー総量と現在値を増やします。

### 召喚・魔法・装備

- モンスターは自分のフィールドに最大6体まで召喚できます。
- 通常のモンスターは、召喚したターンには攻撃できません。
- 魔法は使用すると効果を発揮し、墓地へ送られます。対象が必要な場合は光っている対象を選びます。
- アイテムは味方モンスターに装備し、パワーや能力を追加します。装備数の上限はありません。
- モンスターが破壊されると、装備も墓地へ送られます。

### 攻撃と防御

- 自分のモンスターを選択して「攻撃する」を押し、相手の体力か敵モンスターを選びます。
- 敵モンスターがいる場合も、相手への直接攻撃を選べます。
- 直接攻撃では、モンスターのパワー分だけ相手の体力を減らします。
- モンスター同士の戦闘では、パワーの低い方が破壊されます。同値なら両方が破壊されます。
- 通常は1ターンに1回攻撃できます。自分のターン開始時に未行動に戻ります。
- ブロッカーは、未行動かつ召喚酔いしていないとき、攻撃を1回だけ自身に誘導できます。ブロックすると行動済みになります。

### 五属性と能力

カード180種を、火・水・木・光・闇へ分類しています。各属性36種（モンスター20・魔法10・アイテム6）です。種族とは別の分類で、図鑑とデッキ編集から属性で絞り込めます。

| 属性 | 主な能力 |
| --- | --- |
| 火 | 敵モンスターの効果破壊・味方の永続パワー強化 |
| 水 | 手札を引く・敵モンスターを相手の手札に戻す |
| 木 | エネルギー総量と現在値を増加・自分の体力を回復 |
| 光 | ブロッカー・相手のカード効果に対する能力耐性 |
| 闇 | デッキから墓地へ送る・味方モンスターを墓地から回収／復活召喚 |

#### 光の耐性

- 相手のモンスター・魔法・アイテムによる破壊や手札への帰還を防ぎます。
- 戦闘による破壊や直接攻撃は防ぎません。
- 自分のカードによる強化・装備は受けられます。
- 魔法で付与したブロッカーと耐性は、そのモンスターが場を離れるまで維持されます。

#### 墓地・回収・復活

- 両プレイヤーの墓地ボタンから、墓地にあるカードを閲覧できます。
- 破壊されたモンスター、その装備、使用済みの魔法、デッキから墓地へ送られたカードを墓地で管理します。
- 回収・復活の対象は味方のモンスターのみです。破壊されたものも、デッキから墓地へ送られたものも対象になります。
- 闇の魔法では、墓地から対象のカードを選択します。コスト制限を満たさない復活対象や魔法・アイテムは選べません。
- 闇のモンスター・アイテムの自動能力は、デッキ上2枚を墓地に送り、条件を満たす最高コストの味方を自動選択します。同コストは墓地の先頭を優先します。
- 復活は追加エネルギー不要ですが、カードに記載されたコスト制限と場の上限6体を守ります。自動能力で場が満員の場合は復活しません。
- 復活したモンスターは召喚酔いし、以前の装備・強化・付与能力を引き継ぎません。召喚時能力は再発動しません。カード自身のブロッカーや耐性は有効です。
- 自分のデッキを墓地送りで0枚にすると、その時点で敗北します。残りの回収・復活効果は処理しません。
- 水の手札戻しでは装備を墓地へ送り、本体だけ手札へ戻します。

### 勝利条件・補足

- 相手の体力が0以下になるか、相手のデッキが0枚になった時点で勝利します。引けなくなる次のターンまで待つ方式ではありません。
- 手札・体力・エネルギー総量に上限はありません。
- 強化魔法によるパワー上昇は永続です。
- 対戦モードを変更した後は「新しい対戦」で開始してください。
- 編集して保存したデッキは、次の対戦から反映されます。

## 開発・検証

外部のJavaScriptライブラリやパッケージへの依存はありません。検証・HTML再生成にはNode.jsを使用します。

```sh
# 単一HTML版の再生成
node scripts/build.cjs

# ルール検証と40試合の自動対戦
node verify.cjs

# JavaScript構文チェック
node --check dist/engine.js
node --check dist/app.js
```

分割ソース版は `dist/index.html` をブラウザーで開くことでも起動できます。必要に応じて、Pythonでローカル配信できます。

```sh
python3 -m http.server 8000 --directory dist
```

配信後は `http://localhost:8000` を開きます。

### ファイル構成

```text
.
├── arcana-duel.html       # ダブルクリックで遊べる単一HTML版
├── dist/
│   ├── index.html        # 画面構成
│   ├── style.css         # デザイン・レスポンシブ表示
│   ├── engine.js         # カード定義・ゲームルール
│   └── app.js            # 画面操作・CPU・デッキ編集・SVGイラスト
├── scripts/
│   └── build.cjs         # 分割ソースから単一HTML版を生成
├── verify.cjs            # ゲームエンジンの自動検証
└── README.md
```

変更するときは `dist/` を編集し、`node scripts/build.cjs` で単一HTML版へ反映してください。

## 検証状況・現在の制限

- カード180種類・10種族・初期状態・エネルギー・装備・召喚酔い・攻撃・ブロッカー・能力耐性・五属性の効果・墓地回収／復活・体力とデッキ切れによる勝敗・各プレイヤー40枚の保存則を自動検証しています。
- 40試合の自動対戦が終了することを検証しています。
- ブラウザーでの見た目や操作の検証は未完了です。上記の検証はゲームエンジンに対するもので、画面操作全体を保証するものではありません。
- インターネット経由の通信対戦には対応していません。
- デッキ保存はブラウザー・端末ごとです。ブラウザーのデータ削除で消えることがあります。対戦途中の保存には対応していません。
- カードの数値・CPUの戦略・対戦バランスは初期実装段階です。
